# Relocant bot: Малайзия

Telegram-бот для русскоязычных релокантов: следит за сроками пропусков и виз, напоминает заранее, даёт чек-листы и считает дни для налогового резидентства. Только стандартная библиотека Python 3.9+, без зависимостей.

## Что умеет

| Функция | Команды | Тариф |
|---|---|---|
| Сроки документов с напоминаниями за 120/90/60/30/14/7/1 день, в день окончания и после просрочки (набор зависит от статуса) | `/add`, `/my` | 1 документ бесплатно, до 8 в Premium |
| Напоминание про MDAC перед прилётом (за 3 дня, за 1 день, в день прилёта) | `/add` | бесплатно, до 3 поездок |
| Чек-листы, важные факты и предупреждения по статусу | `/checklist` | бесплатно |
| Ссылки на источники с пометкой официальный / вуз / вторичный / форум | `/sources` | бесплатно |
| Счётчик дней в Малайзии за год и порог 182 дня | `/in`, `/out`, `/tax`, `/undo` | Premium (переключается в `.env`) |
| Часовой пояс, удаление всех своих данных | `/tz`, `/forget` | бесплатно |
| Выдача Premium вручную, статистика | `/grant <id> <дней>`, `/stats` | только админ |

Статусы: DE Rantau Nomad Pass, Student Pass, Employment Pass, Dependant Pass, MM2H, безвизовый въезд (по штампу), MDAC.

## Запуск

```bash
cd relocant-bot-my
cp .env.example .env        # впишите BOT_TOKEN от @BotFather и свой ADMIN_IDS
python3 -m relocbot
```

Бот работает через long polling, домен и вебхуки не нужны. На Windows для часовых поясов один раз установите `pip install tzdata`.

Тесты (нужен только `pytest`):

```bash
python3 -m pytest
```

## Как устроено

```
data/statuses_my.json   все факты, сроки напоминаний, чек-листы и источники (правите здесь, код не трогаете)
relocbot/logic.py       даты, выбор напоминаний, подсчёт дней
relocbot/store.py       SQLite
relocbot/bot.py         команды, кнопки, рассылка
relocbot/tg.py          клиент Telegram API на urllib
tests/                  86 тестов
```

Правила напоминаний:
- Пользователь вводит дату окончания из документа (не расчётную): бот ничего не вычисляет за него.
- Если срок уже ближе, чем очередной порог, лишних напоминаний сразу после добавления нет: остаток дней виден в ответе.
- Если бот был выключен и пропустил несколько порогов, придёт одно сообщение по ближайшему сроку, а не пачка.
- Напоминание отправляется один раз, после 403 (бот заблокирован) повторов нет, на сетевую ошибку повтор на следующем цикле.

## Данные: что проверено и что нет

Факты собраны из открытых источников на 01.11.2026 (см. `meta.verified_on`). У каждого статуса есть уровень надёжности: **high / medium / low**, он показывается пользователю. Особенно осторожно относитесь к:

- **MM2H**: источники расходятся по числу уровней, срокам и депозитам, поэтому бот отправляет только на mm2h.gov.my.
- **Dependant Pass**: типовые чек-листы, официальный перечень документов не сверялся.
- **Окно подачи на продление DE Rantau**: источники называют 2 и 3 месяца, в тексте это сказано прямо.
- Часть данных взята со вторичных сайтов и форумов (в `/sources` они помечены). Перед запуском для клиентов сверьте всё с официальными страницами MDEC, MM2H и Иммиграционного департамента и обновите `statuses_my.json`.

Бот не юридическая и не налоговая консультация, это записано в приветствии и в тексте чек-листов. Не добавляйте в бота советы вида «вам нужно / не нужно платить налог»: только факты со ссылкой на источник и напоминания.

## Что НЕ сделано (следующие шаги)

1. **Бот не запускался против настоящего Telegram**: из среды разработки нет доступа к `api.telegram.org`. Логика покрыта тестами с подставным API и локальным HTTP-сервером, но первый живой запуск проверьте руками: `/start`, `/add`, `/my`, дата, кнопки.
2. **Оплата**: сейчас Premium выдаётся вручную через `/grant`. Для автоматической оплаты подключите Telegram Stars (`sendInvoice` с валютой `XTR`, обработка `pre_checkout_query` и `successful_payment`), это отдельный небольшой модуль, который вызывает `store.set_premium_until`.
3. **Продакшен**: запустите как systemd-сервис или в Docker, делайте бэкап `relocbot.sqlite3` (в нём даты документов пользователей).
4. **Другие страны**: добавьте `statuses_<страна>.json` и параметр выбора страны, остальной код от Малайзии не зависит.
5. **Проверка спроса**: до доработок покажите бота 20–30 людям из чатов релокантов в Малайзии и посмотрите, кто возвращается после первого напоминания.
